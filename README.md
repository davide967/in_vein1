# IN VEIN Pavia

Prototipo interattivo per accompagnare gli studenti dell'Università di Pavia nel percorso di avvicinamento alla donazione di sangue.

## Avvio locale

```sh
npm install
npm run dev
```

## Pubblicazione

Il deploy su GitHub Pages viene avviato automaticamente a ogni push su `main` o sul branch di pubblicazione. L'indirizzo pubblico è:

https://davide967.github.io/in_vein1/

## Nota sul prototipo

L'applicazione è una demo front-end: i dati dell'app vengono salvati nel browser e non esiste un backend per account o dati sanitari.
