# In_vein_definitiva

Prototipo interattivo per accompagnare gli studenti dell'Universita di Pavia nel percorso di avvicinamento alla donazione di sangue.

## Avvio locale

```sh
npm install
npm run dev
```

## Pubblicazione

Il deploy su GitHub Pages viene avviato automaticamente a ogni push sul branch di pubblicazione.

https://davide967.github.io/In_vein_definitiva/

## Nota sul prototipo

Questa versione pubblica e una demo front-end. Gli account e i progressi restano nel browser del dispositivo; non caricare dati personali o sanitari. Il file locale `invein_accounts_db.json` non fa parte del deploy.
